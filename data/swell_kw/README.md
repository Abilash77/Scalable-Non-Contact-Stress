# SWELL-KW Dataset

The SWELL-KW (Keystroke Work) dataset is restricted by a specific EULA for research purposes and cannot be redistributed.

**How to obtain:**
1. Visit the [SWELL-KW dataset portal](http://cs.ru.nl/~skoldijk/SWELL-KW/Dataset.html) or the official DANS Easy portal.
2. Sign the required usage agreement.
3. Once approved and downloaded, place the unzipped files in this directory (`data/swell_kw/`).
