# DriveDB Dataset (PhysioNet)

The "Stress Recognition in Automobile Drivers" (DriveDB) dataset requires credentialed access via PhysioNet and cannot be redistributed.

**How to obtain:**
1. Visit the [DriveDB PhysioNet page](https://physionet.org/content/drivedb/1.0.0/).
2. Agree to the PhysioNet Credentialed Data Use Agreement.
3. Download the raw `.dat` and `.hea` files.
4. Place the downloaded files in this directory (`data/raw/drivedb/`).
