# FER2013 Dataset

The FER2013 (Facial Expression Recognition 2013) dataset was originally released as part of a Kaggle competition ("Challenges in Representation Learning: Facial Expression Recognition Challenge"). Due to Kaggle's competition terms and the large number of files (35,000+ images), it is not included in this repository.

**How to obtain:**
1. Visit the [Kaggle FER2013 Competition Page](https://www.kaggle.com/c/challenges-in-representation-learning-facial-expression-recognition-challenge/data).
2. Agree to the competition rules.
3. Download and extract the image archives.
4. Place the extracted `train/` and `test/` folders in `data/fer2013/raw/`.
