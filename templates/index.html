HOW THE INPUTS WORK

KEYBOARD INPUT — TYPING DYNAMICS

The dedicated input box records typing behavior, not the meaning of the sentence: key press and release timing, dwell time, time between keystrokes, and typing rhythm.

REAL KEYBOARD → TYPING DYNAMICS → 7D FEATURES → 10 TEMPORAL SAMPLES → FREIHAUT STRESS MODEL → STRESS / NON-STRESS

HANDWRITING INPUT — WRITING BEHAVIOR

Write naturally with a mouse, touchpad, touchscreen, or stylus. Real strokes are used for stroke width, slant, density, aspect ratio, and intensity/pressure proxy features.

REAL HANDWRITING → STROKE DATA / IMAGE → 9D FEATURES → TEMPORAL BUFFER → HANDWRITING FEATURE SIGNAL

Currently used for real handwriting feature extraction; not a validated stress predictor.

FACIAL

The visitor's real camera is processed for face detection and facial features with a FER emotion signal. FER-2013 is not a stress model.

REAL CAMERA → FACE DETECTION → FACIAL FEATURES / FER EMOTION SIGNAL

EYE / PUPIL

The same real camera supplies face and eye landmarks for the 5D eye feature vector. These features do not independently predict stress.

REAL CAMERA → EYE / LANDMARK DETECTION → 5D EYE FEATURES

SPEECH

The visitor speaks naturally into the real microphone. The existing extractor computes audio features; this is not a RAVDESS stress model.

REAL MICROPHONE → AUDIO FEATURE EXTRACTION → 169D AUDIO FEATURES
